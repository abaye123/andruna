# Functions guest ELF objects import from the host (andruna-linker).
#
# The build generates libandruna_host.so from this list: one empty function
# per name, soname libandruna_host.so. Guest objects link against it the way
# NDK code links against stub libraries; at run time andruna-linker binds
# every name to its host table, entered with the Android convention (System V
# on x86_64, AAPCS64 on arm64). See aosp/bionic/README.md.

# System calls: number in rax (x86_64) or x8 (arm64), arguments in the C
# argument registers, raw kernel result (-errno on failure).

# Threads and the thread pointer.

__andruna_exit_with_stack_teardown
__andruna_set_tls
