# 0045 - Skia and HWUI as guest libraries: Android's configuration minus Rust, Vulkan and RAW

**Status:** proposed, 2026-11-28

## Context
HWUI (frameworks/base/libs/hwui) draws every View; Skia (external/skia)
does its drawing. Both run in the app process as guest code (Android ELF,
ADR 0013) and reach the GPU through OpenGL ES on ANGLE (andruna-gles, ADR
0029 and 0030). Android builds Skia from a generated `Android.bp`
(`libskia`, about 900 sources per architecture) and links it statically
into `libhwui.so`. At our tag that configuration also needs:

- Rust: Fontations (`libskrifa`, the font back end Skia prefers), AVIF
  (`libcrabbyavif_ffi`) and minikin's hyphenator. The guest build has no
  Rust toolchain for Android targets.
- Vulkan (`libvulkan`, the Vulkan Memory Allocator), RAW images
  (`libdng_sdk`, `libpiex`) and Perfetto (`libperfetto_client_experimental`).
- NASM for libjpeg-turbo's x86_64 SIMD routines.
- For the rest of HWUI: libgui and libui (which need libbinder and code
  generated by the AIDL and HIDL compilers), protobuf, statsd and libandroidfw.

## Decision
- **Skia** is built from its `Android.bp` source list through
  `aosp/tools/blueprint.py` (`aosp/modules/skia.cmake`), so a tag update
  picks up Android's list. `aosp/overlay/skia/include/config/SkUserConfig.h`
  replaces Android's generated configuration and keeps every define except
  `SK_VULKAN`, `SK_CODEC_DECODES_AVIF`, `SK_CODEC_DECODES_RAW`,
  Fontations and Perfetto; the matching sources are left out. The result
  is Ganesh GL, the CPU raster back end, PNG, JPEG, WebP, GIF, BMP, ICO and
  WBMP codecs, PDF, and FreeType (used under the FreeType License) for
  fonts, as Android builds without Fontations.
- **Dependencies** are built from their `Android.bp` lists
  (`aosp/modules/skia_deps.cmake`): FreeType, HarfBuzz (with ICU's Unicode
  functions, `HAVE_ICU_BUILTIN`, as Android), libpng, libjpeg-turbo, libwebp,
  Wuffs, expat, ICU. On x64 libjpeg-turbo uses its portable C routines
  (`jsimd_none.c`) instead of the NASM ones; arm64 keeps NEON. The libpng
  license and the IJG license of libjpeg are permissive BSD-family licenses
  and are treated as "BSD" under ADR 0006.
- **minikin** is built without Rust; a patch gated on `ANDRUNA` makes every
  hyphenator entry point use the C++ implementation, which reads the same
  pattern files.
- **Language level.** Skia, HWUI and minikin are compiled as C++23, because
  `<cutils/trace.h>` includes `<stdatomic.h>` from C++, which the newer
  libc++ accepts only from C++23 (the same reason libcutils' `trace-dev.cpp`
  already uses it).
- **HWUI** is built in two steps. `libhwui_core` holds the sources that need
  none of libgui, libui's buffer allocation, libbinder, protobuf or statsd;
  every other source is listed with what blocks it
  ([hwui.md](../plan/phase3/hwui.md)). `libhwui.so`, with the render thread
  and `SkiaOpenGLPipeline`, follows when libbinder and the headers
  generated from AIDL (libgui, graphics.common) and HIDL (graphics.common
  types) are available; until then nothing presents through HWUI. At this
  tag 65 of HWUI's 105 sources compile.
- **Flags and properties.** aconfig flags are compile-time constants at
  their declared defaults (`aosp/tools/aconfig_cc.py`, as for ART);
  `HWUIProperties.sysprop` gets generated accessors over system properties
  (`aosp/tools/sysprop_cc.py`), so `ro.hwui.use_vulkan` and
  `ro.hwui.render_ahead` behave as on a device. With no Vulkan,
  `ro.hwui.use_vulkan` must stay unset or false.

## Consequences
- Apps get Skia's GL and raster rendering and the same image codecs as a
  device, except AVIF and RAW (decoding them fails as on a device without
  the codec: `BitmapFactory` returns null, `ImageDecoder` throws).
- Fonts are FreeType's rendering of the font files; Android's default
  Fontations path renders the same outlines with a different rasterizer,
  so glyph pixels can differ slightly from a current device.
- Adding Rust for Android targets later re-enables Fontations, AVIF and
  minikin's Rust hyphenator by removing the overlay's exclusions and the
  patch.
- Vulkan for HWUI needs a guest `libvulkan` and Skia's Vulkan sources; it is
  outside this decision (ADR 0029 chose D3D11 through ANGLE for HWUI).
